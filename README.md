# 🧠 Silent Classrooms  
### AI-Powered Visual Learning System for Inclusive Education

---

## 📌 Overview

Silent Classrooms is an AI-powered web application designed to make classroom learning accessible and effective for students with hearing impairments.

Traditional education systems rely heavily on spoken communication, which creates a major barrier for deaf and hard-of-hearing students in understanding concepts in real time.

This project transforms teaching into a **visual and interactive learning experience** by automatically generating structured educational content from a given topic.

---

## 🚀 What It Does

Given any subject and topic, the system generates:

- 📖 **Explanation** – Simple and easy-to-understand text  
- 🖼️ **Images** – Visual representations of concepts  
- 🎥 **Animated Videos** – Step-by-step concept explanation  
- ♿ **Accessibility Features**:
  - Visual transcript  
  - Sign language guide (image-based)  
  - Visual captions  

This enables students to **see, understand, and learn concepts**, rather than relying only on audio-based teaching.

## 🧩 Tech Stack

- **Frontend:** React.js, Tailwind CSS

- **AI Integration:** LLM APIs (Groq / OpenAI / Gemini)  
- **Media APIs:** YouTube, Pixabay
